# DineReserve - Restaurant Table Booking System (Luxe Dining)

A premium restaurant table booking system built with React, Vite, and Bootstrap. This application provides a modern, responsive, and dynamic user interface for customers to browse menus, select dining tables, and make reservations.

## Features

- **Premium UI/UX**: High-end visual identity ("Luxe Dining") using custom CSS and glassmorphism styling.
- **Interactive Reservations Page**:
  - Custom Date and Time Selection
  - Guest Count Selector
  - Interactive Restaurant Floor Plan (Available, Booked, and Selected states)
  - Table Detail Cards
- **Responsive Layout**: Fully adaptive design for mobile, tablet, and desktop viewing.

## Technologies Used

- **React 18**
- **React Router DOM 6** (Client-side routing)
- **Vite** (Build tool and development server)
- **Bootstrap 4** (Layout and base components)
- **Custom Native CSS** (Premium styling and layouts)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone or download the repository.
2. Navigate to the project directory:
   ```bash
   cd tablebookin_system
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server:

```bash
npm run dev
```

Open your browser and navigate to the URL provided in the terminal (usually `http://localhost:5173`).

### Building for Production

To create a production-ready build

```bash
npm run build
```

This will generate a `dist` folder containing the optimized static assets.
